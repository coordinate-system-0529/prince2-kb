## 本版结构

- 原有十章项目计划文件保留。责任分工和流程使用直接位于文件下方，不再藏在字段说明弹窗中。
- 八个角色列、七项活动行的责任矩阵。案例列同时显示人物和现实身份；A表示问责，批准作为授权活动单独呈现。
- 六个场景：首次编制、审查授权、执行中检查、阶段复查、预测超差、收尾对照。
- 活动行与场景联动。步骤按责任人、使用材料与动作、产出与交接排列，材料链接指向计划章节或对应双模式产品。
- 工作包、阶段和项目三层超差分别显示升级路径，不将例外计划视为自动生成，不把项目管理委员会的权限扩展到项目外部。
- 理论与案例使用相同目录和导航；案例保留教学情境、拟稿、待确认等状态。说明不代替实际文档，不混入正式文件打印。
