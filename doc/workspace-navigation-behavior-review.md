## 问题与修复

| 问题 | 修复及证据 |
|---|---|
| 同一章节重复点击无定位 | 风险案例首次点击责任分工位于84像素，回页首再次点击后仍在页首，已实际复现。现明确处理同文档锚点，重复点击重新定位，不重复增加历史项 |
| 历史恢复被后续hash事件覆盖 | 同路由历史变化不再整页重绘，历史恢复与后续hash事件分开；匹配产品、模式及hash后读取保存位置，新的定位请求使旧异步任务失效 |
| 旧字段链接覆盖手动选择 | 实际复现RISK-007字段链接进入后手选RISK-011，切理论再返回却回到RISK-007。现历史项保存记录快照，刷新和返回优先恢复后来选择；新打开的明确字段链接仍选中目标记录 |
| 理论字段与案例章节别名冲突 | 可见案例章节优先于关闭说明框内的同名理论ID。项目计划预算、完整商业论证成本在四种宽度下直接定位及模式往返通过 |
| 关闭内容参与阅读位置捕获 | 排除隐藏祖先、关闭说明框和关闭details中的字段；关闭details内容即使返回缓存矩形，也不作为当前阅读项 |
| 显式跳转后旧场景阅读意图残留 | 三类流程使用模块提供阅读意图重置接口，明确章节定位后不再沿用旧场景意图；不伪造hashchange事件 |

保留字段说明／案例解读弹窗的原点击逻辑、跳到正文的原生键盘行为，以及修饰键、新窗口、下载和跨页链接行为。

### 验证过程中的区别

浏览器自动化的鼠标定位会在点击之前将目标滚入视区，因此不能把操作前后的读数差异直接判定为站点历史恢复错误。已用键盘Enter隔离该影响，章节内部阅读位置及原文返回通过。临时诊断输出已移除。

初轮原文件保护检查因两个使用脚本新增接口而失败，已保留旧快照、仅精确排除该新增接口后重跑通过，不更新图谱、正文或数据基准。临时诊断期间测试夹具缺少console.debug的报错不作为交付结果，移除诊断后54项重新通过。
